# Food Delivery Order Processor

A command-line Python application that processes food delivery orders, calculates bills, applies discounts, and generates daily sales reports.

## Features
- Menu management using dictionaries.
- Processing multiple sample orders.
- Automatic bill calculation.
- 10% discount on orders of Rs. 500 or above.
- Fixed delivery charge of Rs. 30.
- Invalid item and empty order handling.
- Highest-value order identification.
- Daily sales report generation using file handling.

## Technologies
- Python 3
- Lists and Dictionaries
- Functions
- Conditional Statements
- Loops
- File Handling

## Execution

```bash
python food_delivery.py
```

## Files
- `food_delivery.py` – Main program.
- `sample_orders.txt` – Sample menu and orders.
- `sales_report.txt` – Generated sales report.
- `obstacle_log.md` – Problems encountered and solutions.
